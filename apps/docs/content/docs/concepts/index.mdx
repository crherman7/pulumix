## Deployment Flow

1. **Configuration** - Load stack and project settings
2. **Discovery** - Scan for services in project and node_modules
3. **Dependency Resolution** - Build graph, determine order
4. **Bootstrap** - Ensure cluster resources exist
5. **Build** - Build Docker images with content-based caching
6. **Deploy** - Apply Pulumi resources in topological order
