The example project demonstrates a complete Pulumix deployment with multiple services.

## Overview

Located in `apps/example/`, this project includes:

- **provider** - Creates k3d cluster with local registry
- **ingress** - Configures ingress (uses k3d's built-in Traefik)
- **hello-world** - Builds and deploys HTTP service with Ingress

## Running the Example

```bash
cd apps/example
pnpm install
pnpm run deploy local
```

## Service Details

### Provider

Creates a k3d cluster with a local Docker registry:

```typescript title="services/provider/pulumix.ts"
export default async (ctx: ServiceContext): Promise<ServiceResult> => {
  // Create k3d cluster
  const cluster = new k3d.Cluster(ctx.serviceName, {
    registry: { create: true }
  })

  return {
    outputs: {
      kubeconfig: cluster.kubeconfig,
      registryUrl: cluster.registryUrl
    }
  }
}
```

### Hello World

Deploys an Express HTTP server:

```typescript title="services/hello-world/pulumix.ts"
export default async (ctx: ServiceContext): Promise<ServiceResult> => {
  const { serviceName, namespace, config, image } = ctx

  const deployment = new k8s.apps.v1.Deployment(serviceName, { ... })
  const service = new k8s.core.v1.Service(serviceName, { ... })
  const ingress = new k8s.networking.v1.Ingress(serviceName, { ... })

  return {
    outputs: {
      url: `http://${serviceName}.${config.baseDomain}/`
    }
  }
}
```
