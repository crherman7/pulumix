Pulumix uses YAML configuration files at two levels:

1. **Project root** (`pulumix.yaml`) - Global settings, security allowlists, stack configuration
2. **Service manifest** (`services/*/pulumix.yaml`) - Service-specific metadata, observability, stack overrides

## File Locations

```
my-project/
├── pulumix.yaml              # Project root config
├── services/
│   ├── api/
│   │   ├── pulumix.yaml      # Service manifest
│   │   └── pulumix.ts        # Deployment logic
│   └── web/
│       ├── pulumix.yaml
│       └── pulumix.ts
└── package.json
```
