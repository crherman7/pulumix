---
title: Service Manifest
description: Service pulumix.yaml configuration
---

Each service has a `pulumix.yaml` manifest defining its metadata, observability settings, and stack-specific configuration.

## Full Example

```yaml title="services/my-api/pulumix.yaml"
metadata:
  name: my-api
  version: 1.0.0
  description: My API service
  team: backend
  owner: backend@company.com
  tags:
    tier: api
    criticality: high

observability:
  health:
    endpoint: /health
    port: 3000
  metrics:
    endpoint: /metrics
    format: prometheus
  logs:
    format: json
    level: info

# Local development configuration
dev:
  command: npm run dev
  port: 3000
  cwd: src
  env:
    NODE_ENV: development

stacks:
  local:
    replicas: 2
    baseDomain: '127.0.0.1.sslip.io'

  production:
    replicas: 10
    baseDomain: 'api.company.com'
```

## Fields

### `metadata`

Service identification and ownership information.

| Field | Required | Description |
|-------|----------|-------------|
| `name` | Yes | Service name (must match package.json name) |
| `version` | Yes | Semantic version |
| `description` | No | Human-readable description |
| `team` | No | Owning team name |
| `owner` | No | Owner email or contact |
| `tags` | No | Key-value labels for categorization |

### `observability`

Observability configuration for health checks, metrics, and logging.

#### `observability.health`

```yaml
observability:
  health:
    endpoint: /health    # Health check path
    port: 3000           # Health check port
```

#### `observability.metrics`

```yaml
observability:
  metrics:
    endpoint: /metrics   # Metrics endpoint
    format: prometheus   # Metrics format
```

#### `observability.logs`

```yaml
observability:
  logs:
    format: json         # Log format (json, text)
    level: info          # Log level
```

### `dev`

Local development configuration for `pulumix dev` command.

| Field | Required | Description |
|-------|----------|-------------|
| `command` | Yes | Command to run locally (e.g., `npm run dev`) |
| `port` | Yes | Dev server port |
| `cwd` | No | Working directory relative to service root |
| `env` | No | Additional environment variables |

```yaml
dev:
  command: npm run dev
  port: 3000
  cwd: src
  env:
    NODE_ENV: development
    DEBUG: "app:*"
```

### `stacks`

Per-stack configuration overrides. Each key matches a Pulumi stack name.

```yaml
stacks:
  local:
    replicas: 2
    baseDomain: '127.0.0.1.sslip.io'

  production:
    replicas: 10
    baseDomain: 'api.company.com'
    resources:
      cpu: "500m"
      memory: "512Mi"
```

Stack configuration is available in `pulumix.ts` via `ctx.config`.

## Minimal Example

For simple services, only `metadata` is required:

```yaml title="pulumix.yaml"
metadata:
  name: my-service
  version: 1.0.0
```
