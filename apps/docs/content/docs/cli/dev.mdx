---
title: dev
description: Run services locally with hot module replacement
---

Run services locally with hot module replacement (HMR) while dependencies run in the cluster. The cluster's ingress URL routes to your local machine for full-stack development.

## Usage

```bash
pulumix dev <stack> <services> [options]
```

## Arguments

| Argument | Description |
|----------|-------------|
| `stack` | Stack name (e.g., `local`) |
| `services` | Comma-separated list of services to run locally |

## Options

| Option | Description |
|--------|-------------|
| `-p, --path <path>` | Project root (default: cwd) |
| `-v, --verbose` | Verbose output |

## Examples

```bash
# Single service dev
pulumix dev local web-app

# Multiple services (full-stack dev)
pulumix dev local web-app,api

# From different directory
pulumix dev local hello-world -p ./apps/example
```

## How It Works

1. **Discovery** - Finds all services and their dependencies
2. **Compute** - Determines which services run locally vs in cluster
3. **Port-forwards** - Sets up port-forwards to cluster services (databases, etc.)
4. **Scale down** - Scales down cluster deployments for dev services
5. **Patch services** - Routes Kubernetes Services to your local machine
6. **Start dev servers** - Launches local dev servers with injected environment variables
7. **Route traffic** - Ingress URLs now hit your local dev server

## Requirements

Services must have a `dev` section in their `pulumix.yaml`:

```yaml title="pulumix.yaml"
metadata:
  name: my-api
  version: 1.0.0

dev:
  command: npm run dev    # Command to run locally
  port: 3000              # Dev server port
  cwd: src                # Working directory (optional)
  env:                    # Additional env vars (optional)
    NODE_ENV: development

stacks:
  local:
    baseDomain: '127.0.0.1.sslip.io'
```

## Cleanup

Press `Ctrl+C` to stop dev mode. Pulumix will:

1. Stop local dev servers
2. Restore original Kubernetes Service configuration
3. Scale deployments back up
4. Stop port-forwards

If dev mode crashes, Pulumix saves state to `.pulumix/dev-state.json` and automatically restores on next run.

## Multi-Service Development

When running multiple services locally:

```bash
pulumix dev local web-app,api
```

Pulumix automatically:

- Assigns unique local ports (3000, 3001, ...)
- Injects environment variables so services can communicate
- Routes all ingress URLs to respective local servers

For example, `web-app` gets:
```
API_URL=http://localhost:3001      # Local api
DATABASE_URL=postgres://localhost:5432  # Cluster postgres via port-forward
```
